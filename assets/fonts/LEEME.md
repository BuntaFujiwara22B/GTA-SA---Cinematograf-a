# Namche Shape

`NamcheShape-Origin.ttf` es la fuente original **Namche Shape Origin**, estilo
Regular, de Michael Marte, derivada de la cuadrícula Geist Pixel. Se incluye
localmente para que el título de MMS-Director funcione sin conexión a Internet.

Fuente oficial: https://github.com/NamcheAI/namche-fonts

Archivo original:
https://raw.githubusercontent.com/NamcheAI/namche-fonts/main/fonts/NamcheShape/ttf/NamcheShape-Origin.ttf

Distribuida bajo SIL Open Font License 1.1. Consulta `OFL-Namche.txt` para la
licencia completa y `AUTHORS-Namche.txt` para los créditos conservados del
proyecto original y sus derivados. Los archivos TTF se distribuyen sin modificar.
